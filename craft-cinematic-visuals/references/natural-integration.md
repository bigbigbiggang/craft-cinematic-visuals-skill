# 自然融合与素材承受度

处理现有照片或视频时使用。目标不是让风格更明显，而是让结果像原本就以这种方式拍摄和调色。

## 1. 先读原片

记录原片自身的“摄影签名”：

- 媒介：监控、手机、相机、扫描、屏幕截图、渲染或未知。
- 镜头：景深、透视、边缘表现、锐度和畸变。
- 光源拓扑：光源数量、方向、软硬、衰减、阴影和反射。
- 曝光：黑位、高光、动态范围和第一视觉落点。
- 色彩：白平衡、混合色温、肤色、环境反射和色彩密度。
- 纹理：噪点、压缩、锐化、运动模糊和表面材质。

任何修改都应延续这些关系。调色不能改变物理事实。

## 2. 判断改动层级

### L0 原样保护

只修复明显技术问题：错误白平衡、轻微偏色、过曝边缘、数字锐化。适合证据、档案、文字和产品素材。

### L1 自然校正

调整整体曝光、柔和曲线、局部层级和适度饱和度。观众不应察觉“套了风格”。

### L2 情绪调色

在 L1 基础上，轻微改变阴影/高光冷暖、色彩密度和黑位性格。仍保持原始光源、时代和媒介。

### L3 摄影重构

改变时间、天气、光源方向、景深、镜头、美术或时代。必须使用生成式编辑或重新制作，并向用户标明这不是纯调色。

用户只说“更有电影感”时，默认停在 L1–L2。

## 3. 政策：光源拓扑不可伪造

调色可做：

- 压低过亮墙面或背景。
- 温和提亮已有受光区域。
- 调整整体或区域对比。
- 控制高光滚降和阴影密度。
- 利用原有亮度关系加强视觉顺序。

调色不可做：

- 在无光源依据处制造聚光灯。
- 新增硬轮廓光、窗影、百叶影或彩色灯。
- 把均匀顶光改成戏剧性侧光。
- 制造与物体形状不一致的新阴影。
- 用暗角模拟不存在的空间光衰减。

如果需要这些变化，归入 L3。

## 4. 风格吸收预算

每项从 0 到 3 评分：

- **曝光预算**：能否压暗或提亮而不丢失关键细节。
- **色彩预算**：肤色、白墙、品牌色和中性色能承受多少偏移。
- **对比预算**：高光和暗部是否有空间增加密度。
- **质地预算**：原片分辨率、噪点和压缩是否允许柔化或加颗粒。
- **局部调整预算**：是否有真实亮度区域可供强化。

任一项为 0 时不修改该轴。监控和截图通常色彩、质地预算低；RAW 或高质量摄影通常预算较高。

## 5. 分区而非全局覆盖

- 白墙、纸张和文字优先保持中性与可读。
- 肤色与环境色分开控制，不让全局冷暖污染皮肤。
- 金属、玻璃、布料和皮肤保留不同反射特征。
- 阴影可略有色偏，高光尽量接近光源颜色。
- 颗粒强度随亮度和原始噪点变化，不平均覆盖。

## 6. 自然度检查

缩小到缩略图并问：

1. 第一眼看到的是人物/事件，还是滤镜？
2. 光是否仍像来自原来的位置？
3. 白色物体是否仍像白色？
4. 肤色是否仍有血色和局部差异？
5. 影像质地是否与分辨率和媒介一致？
6. 关闭效果后，变化是否主要是层级更清楚而非世界被替换？

任意两项失败，就降低强度或回到 L1。
