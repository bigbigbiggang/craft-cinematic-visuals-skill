# 多版本工作流

用于现有素材的自然探索。多版本的目标是帮助用户找到合适强度，不是证明风格数量。

## 默认三版

| 版本 | 改动层级 | 目标 |
|---|---|---|
| A 自然平衡 | L1 | 修正曝光、白平衡、曲线和数字锐度，最接近原片 |
| B 情绪偏移 | L2 轻度 | 只改变一个情绪轴，如略冷、略暖、略低调或略通透 |
| C 质感增强 | L2 中度 | 沿 B 的方向增加密度、局部层级与轻微质地 |

三个版本共享原始摄影逻辑。不要为了拉开差异而改变时代、光源、镜头、景深或场景。

## 差异规则

- 每版只改变 1–2 个主轴。
- A 与原片应像同一摄影师的基础校色。
- B 应在不看说明时仍显自然，只是情绪略有倾向。
- C 可以被察觉为完成调色，但不应先被识别为滤镜。
- 用户明确要求不同类型方向时，先给文字方向板；选定后再制作，避免一次生成多个生硬重构。

## 处理方式

### 非生成式

现有照片默认使用 `scripts/grade_image.py`：

```bash
<workspace-python> scripts/grade_image.py \
  --input input.png \
  --output output.png \
  --preset source-neutral \
  --strength 0.5
```

先调用 `load_workspace_dependencies` 获取 `<workspace-python>`。脚本依赖 Pillow 和 NumPy。

内置预设：

- `source-neutral`：中性自然校正。
- `cool-contained`：轻微冷静，保护中性色和肤色。
- `warm-muted`：轻微温暖，降低数字生硬感。
- `dense-neutral`：增加密度和层次，不明显改变色温。

`--strength` 建议范围为 `0.25–0.7`。超过 `0.75` 前先检查是否已经像滤镜。

可使用多个保护区域保持文字、Logo 或界面像素完全不变：

```bash
--protect-rect 0,0,500,120 --protect-rect 1160,0,1448,120
```

### 生成式

只用于 L3 重构。每个版本从原图独立开始，并明确标注“摄影重构”，不要与自然调色版本混为一组。

## 比较输出

每版只说明：

- 改了什么。
- 为什么适合当前素材。
- 强度等级。

避免用“七十年代偏执”“高反差心理密室”等大标题包装微小调色。名称应直接描述实际变化，例如：

- 自然平衡
- 冷静一点
- 更密实但保持中性

## 反馈迭代

用户说“生硬”“像滤镜”“不像原片”时：

1. 停止增加风格元素。
2. 回到原图，不以上一版为基础。
3. 将处理层级降一级。
4. 保留原白平衡和光源拓扑。
5. 减半色偏、暗角、颗粒、辉光和局部曝光幅度。
6. 用非生成式调色重新输出。
