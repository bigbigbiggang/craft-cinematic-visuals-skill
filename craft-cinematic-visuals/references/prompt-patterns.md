# 提示词与交付模板

根据任务选择一个模板。保留逻辑顺序，删除无关项，不要为了完整而填写空洞参数。

## 通用主提示词

```text
【主体与具体动作】位于【场景、时代、时间、天气】。
画面捕捉【决定性瞬间与情绪】，观众首先注意【视觉焦点】。
【景别与构图】，机位【高度、角度、距离】，呈现【广角/标准/长焦的视觉效果】，
【景深选择及理由】，前景【遮挡或引导】，背景【需要保留的信息】。
光线由【可信光源】驱动，方向【方向】，质地【软硬】，明暗关系【对比与曝光】，
重点保护【皮肤/高光/暗部细节】。
色彩以【主色】为主，【辅色】分离主体，【强调色】只出现在【位置】；
美术与材质强调【关键道具、服装、表面】。
摄影机【静止或具体运动】，速度【节奏】，运动服务【叙事目的】。
影像质地【颗粒、锐度、高光响应、轻微镜头行为】，整体保持【真实度】。
必须保持【身份、产品、文字、构图或连续性锚点】。
避免【3–6 个当前任务最可能出现的失败项】。
```

## 图像生成

交付：

1. 探索模式默认建立 3 个方向，每个方向各有一句叙事意图和一份独立提示词。
2. 精修模式提供一份主提示词和必要的强度备选。
3. 每个方向提供短负面约束。
4. 必要时补充画幅与构图安全区。

不要加入无法从单帧看出的声音或复杂剪辑描述。需要系列图时，固定人物、服装、色板、时间、镜头规则和材质锚点。

## 图像编辑

先判断处理层级。L0–L2 不写生成式提示词，改用 `scripts/grade_image.py`。只有 L3 才继续使用以下编辑边界。

先写编辑边界：

```text
保持不变：
- 人物身份、五官比例、姿态和视线
- 产品几何、Logo、包装文字
- 原始场景结构与主要物体位置

允许改变：
- 光线方向与明暗比
- 背景层次与局部色彩
- 材质响应、空气感和影像质地
```

再写编辑动作，按“修正结构 -> 重塑光线 -> 统一色彩 -> 添加质地”的顺序。除非用户明确要求，不要擅自增删人物、道具、文字或环境元素。

生成式探索先写一份所有版本共享的保持不变清单，再为每版写专属变化。每个版本都以原图为输入，不以上一版为输入。

```text
版本名：【情绪/类型 + 摄影逻辑】
叙事解释：【该版本如何重新解释同一时刻】
专属变化：
- 光线：【光源、方向、区域与对比】
- 色彩：【主色、辅色、肤色策略】
- 空间：【主体与环境权重】
- 质地：【时代、媒介、锐度、颗粒、高光响应】
风格强度：【低 / 中 / 高】
主要风险：【最可能损害保真或可读性的点】
```

## 文生视频

```text
起始状态：【主体、姿态、场景关系】
动作过程：【一个主要动作 + 一个次要环境反应】
结束状态：【动作落点与构图结果】
摄影机：【起点、运动路径、速度、终点】
时间节奏：【时长感、是否慢动作、关键节拍】
光线变化：【保持稳定或随事件发生的合理变化】
连续性：【身份、服装、肢体、物体数量、背景结构】
声音建议：【环境底噪、近景细节、画外声、音乐留白】
避免：【形体变形、无故运镜、速度跳变、背景漂移、闪烁】
```

一个镜头只设一个主要摄影机动作。复杂镜头拆成多个镜头或明确分阶段，不在短时长里同时推进、环绕、升降、变焦和甩镜。

## 图生视频

先读取首帧中的真实关系，再补充：

- 哪些像素关系必须锁定。
- 哪个主体先动，动作幅度多大。
- 环境中只有哪些元素产生次级运动。
- 摄影机是静止、轻推、横移还是跟随。
- 结尾如何落回稳定构图。

默认使用小幅、可控、物理合理的运动。不要让所有头发、衣服、灯光、云、树和摄影机同时剧烈运动。

## 分镜

每个镜头使用以下字段：

```text
镜号 / 预计时长
叙事功能
画面与动作
景别 / 机位 / 镜头倾向
摄影机运动
光线与色彩
声音与衔接
连续性锚点
```

镜头变化必须带来新信息、情绪推进或节奏作用。两个镜头功能相同则合并。

## Look Bible

至少包含：

- 一句视觉命题
- 叙事关键词 3 个
- 禁用关键词 3 个
- 构图规则
- 镜头与机位规则
- 光线规则
- 色板与肤色规则
- 美术与材质规则
- 运动与剪辑规则
- 影像质地规则
- 声音规则
- 连续性锚点
- 正确示例与反例的可观察差异

## 素材诊断

按影响从高到低列出问题：

```text
1. 问题：可观察事实
   影响：它如何削弱叙事或主体层级
   修改：具体可执行动作
   优先级：高 / 中 / 低
```

不要把主观偏好写成技术故障。区分“画面不符合目标方向”和“画面本身存在连续性、曝光或可读性问题”。
