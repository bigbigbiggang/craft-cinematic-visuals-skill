# 电影质感创作

把“电影感”拆成叙事、场面调度、摄影、光线、色彩、质地、运动与声音等可控制变量。现有素材先识别它本来是什么，再做它能够自然承受的改动；电影质感应像来自拍摄与调色，而不是覆盖在画面上的风格模板。

## 工作流程

### 1. 判断任务模式

先识别用户需要的交付物：

- **概念设计**：从文字建立视觉方向、look bible、分镜或提示词。
- **素材诊断**：分析已有图像或视频为何缺少电影感，并按影响排序提出修改。
- **素材改造**：直接编辑或生成画面，同时保护人物身份、产品结构、品牌文字与空间连续性。
- **拍摄方案**：给出机位、焦段、光线、调度、运动、声音和后期建议。
- **提示词适配**：为指定图像或视频模型生成结构清楚、可复制执行的提示词。
- **风格探索**：围绕同一素材生成多个类型片、时代影像或摄影传统方向，帮助用户比较选择。

如果用户要求直接生成或编辑，并且存在相应工具，执行制作而不只停留在提示词。只有缺少会显著改变方向的信息时才提问；其余信息做保守假设并明确说明。

### 2. 选择处理方式

先判断是“保留摄影”还是“重构摄影”：

- **非生成式调色**：现有照片、截图、监控、档案、产品和含重要文字的图像默认使用。保持所有像素几何、身份、文字和物体不被重画，只调整曝光、曲线、白平衡、局部层级、饱和度、锐度与轻微质地。优先运行 [grade_image.py](scripts/grade_image.py)。
- **生成式编辑**：仅在用户明确要求改变天气、时间、光源结构、场景、服装、构图、物体或进行明显艺术化重构时使用。提前说明它可能重画人物、文字和细节。
- **从零生成**：没有既有素材，或用户希望重新创作场景时使用。
- **方案设计**：只输出拍摄、调色、分镜或提示词，不直接处理素材。

不要仅因为存在图像生成工具就使用生成式编辑。对于“把这张照片变得更有电影感”，默认选择非生成式调色。

### 3. 评估素材承受度

在选择风格前读取 [natural-integration.md](references/natural-integration.md)，确定：

- 原始媒介：电影机、手机、监控、屏幕截图、扫描、渲染或未知。
- 原始光源拓扑：主要光从哪里来，哪些阴影和反射已经固定。
- 动态范围、锐度、景深、压缩和噪点特征。
- 不可重写的事实：身份、文字、产品、空间、时代和事件证据。
- 可自然调整的预算：色温、对比、区域曝光、色彩密度和质地各能改变多少。

如果一个风格要求改变原片不存在的光源、镜头、景深、美术或时代信息，它不属于调色，应归为生成式重构并征得用户明确意图。

### 4. 选择探索或精修模式

- **探索模式**：用户未指定明确风格、要求“电影感”“多来几个”或对上一版不满意时使用。现有素材默认提供 3 个渐进版本：自然校正、情绪偏移、质感增强。用户明确要求数量时遵从用户。
- **精修模式**：用户已经选定某个方向或提供清晰参考时使用。围绕该方向生成 1 个主版本，必要时增加 1 个强度不同的备选。
- **诊断模式**：用户只要求分析时不生成结果，按影响排序指出问题并给出 3 条可执行路线。

现有素材的多版本不追求夸张差异。保持同一摄影逻辑，每版只改变 1–2 个主轴，并使用低、中、较高但自然的强度梯度。概念设计或从零生成才可探索差异显著的类型片方向。

### 5. 提炼叙事意图

用一句话锁定以下内容：

- 主体是谁或是什么。
- 此刻正在发生什么。
- 观众应该先看哪里、感到什么。
- 画面的时代、地点、时间与天气。
- 真实度位于纪实、自然主义、风格化和超现实之间的哪一段。

先写“叙事句”，再写“风格句”。例如：

> 叙事句：深夜下班的人独自在便利店短暂停留，疲惫中有一点安全感。  
> 风格句：冷雨街道包围暖色室内，克制观察，低对比高光，细微手持呼吸。

### 6. 设计视觉层级

按以下优先级做决定：

1. **叙事与表演**：动作、眼神、关系、决定性瞬间。
2. **调度与构图**：主体位置、前中后景、遮挡、负空间、视线方向。
3. **光线与曝光**：光源动机、方向、软硬、明暗比、高光控制。
4. **镜头与机位**：景别、焦段倾向、距离、机位高度、景深。
5. **色彩与美术**：主辅色、肤色、材质、服装、场景陈设。
6. **运动与时间**：演员运动、摄影机运动、节奏、快门感、速度变化。
7. **质地与后期**：颗粒、晕光、色散、锐度、压缩感、画幅。

需要更细的判断时读取 [cinematic-language.md](references/cinematic-language.md)。

### 7. 建立方向组

处理现有素材时先读取 [multi-variant-workflow.md](references/multi-variant-workflow.md)，默认使用同源渐进结构：

1. **自然平衡**：修正曝光、白平衡和层级，几乎不显风格。
2. **情绪偏移**：在不改变光源拓扑的前提下，轻微偏冷、偏暖、压低或通透。
3. **质感增强**：沿用户更可能喜欢的方向增加密度、柔化数字感和局部层次，但保持可信。

概念设计、从零生成或用户明确要求类型片探索时，才读取 [film-style-atlas.md](references/film-style-atlas.md)。类型片名称只用于选择，最终执行描述必须回到原片可实现的摄影变量。

精修模式只设一个主视觉命题，并最多增加两个辅助特征。避免同时堆叠互相竞争的标签。

需要快速选择宽泛方向时读取 [look-archetypes.md](references/look-archetypes.md)。把参考电影、剧集、摄影师或导演拆解为可观察属性，不依赖专有名称作为提示词主体，不复制单一在世创作者的独特风格。

### 8. 形成可执行描述

按因果顺序组织方案或提示词：

1. 主体与动作
2. 场景、时间与天气
3. 构图、调度与机位
4. 镜头、焦段倾向与景深
5. 动机光、曝光与明暗关系
6. 色彩、美术与材质
7. 摄影机运动与时间节奏
8. 影像质地与后期约束
9. 必须保留与必须避免的内容

不要只列形容词。把“高级、氛围、电影感”改写为可见、可拍、可调的特征。提示词结构和不同任务模板见 [prompt-patterns.md](references/prompt-patterns.md)。

### 9. 制作、比较并收敛

现有照片优先使用 `scripts/grade_image.py` 从原图独立输出各版本。运行前调用 `load_workspace_dependencies` 获取带 Pillow 和 NumPy 的 Python 路径。需要保护文字或图形时使用一个或多个 `--protect-rect x1,y1,x2,y2` 保留原始像素。运行后实际查看结果，避免肤色偏移、黑位堵塞、白墙染色和颗粒过重。

只有进入生成式编辑时，才为每个方向发起独立生成；每次都以原始素材为输入，不以上一版为输入。

把结果并列展示，并用一句话说明每版的核心变化。不要替用户假装选定最终方向。用户选定后进入精修模式，保留选中版本的视觉 DNA，只调整反馈中点名的问题。

交付前读取或应用 [quality-control.md](references/quality-control.md) 的检查项。优先删除无叙事作用的效果，而不是继续添加装饰。

## 输入素材规则

处理已有图像或视频时：

1. 先描述素材中确定存在的内容，不臆造关键事实。
2. 列出必须保持不变的锚点：身份、五官、服装、产品几何、Logo、文字、动作、视线、场景结构或镜头连续性。
3. 区分可改变量与不可改变量。
4. 对低清、遮挡或画外信息使用条件性表述。
5. 先修光线、主体分离和构图，再加颗粒、辉光或画幅等表层效果。
6. 不改变已经拍定的光线方向；调色可以压暗或提亮区域，但不能凭空制造硬光边界、轮廓光或新的阴影。
7. 不把监控、手机、档案等媒介伪装成 35mm 摄影；可以优化其电子影像特征，但保留媒介身份。

## 输出格式

默认用简洁、制作导向的结构输出。探索模式使用以下格式：

### 方向概览

先用表格或短列表列出版本名、核心情绪、主要变化和风格强度。

### 版本 A / B / C

每版包含一句视觉意图、关键电影语言和对应结果或提示词。版本名称描述视觉逻辑，例如“冷峻程序现实主义”，不要只写“方案一”。

### 推荐判断

说明每版最适合的叙事用途和主要风险。可以给出专业倾向，但不替用户做最终选择。

精修或单版本任务使用以下格式：

### 视觉意图

用 1–2 句话说明叙事与情绪，不堆风格词。

### 电影语言方案

覆盖构图、镜头、光线、色彩、美术、运动和质地；只写对当前任务有影响的项。

### 最终提示词或执行清单

给出一份可直接使用的主版本。指定模型时适配其语法；未指定时使用自然语言模块化提示词。

### 负面约束

只列高风险失败项，例如身份漂移、塑料肤质、无动机轮廓光、过度锐化、随机景深、文字变形、运动不连续。不要塞入冗长的通用负面词表。

### 备选方向

精修模式仅在当前方向存在明显强度分叉时补充 1 个备选。探索模式不使用本节，因为多方向本身就是主要交付物。

## 质量原则

- 让光线看起来来自场景中的窗、灯、天空、火、屏幕或反射面。
- 让景深服从观看重点和空间信息，不默认使用极浅景深。
- 让颗粒、晕光、镜头缺陷服从媒介与曝光，不均匀覆盖全部画面。
- 让肤色在风格化调色中仍有可信血色与明度层次。
- 让黑位保留必要信息，高光有层次，不把“电影感”等同于欠曝。
- 让摄影机运动有观察动机；静止镜头同样可以具有电影感。
- 让每个视觉选择能回答“它如何服务此刻的故事”。
- 让自然度高于风格辨识度；用户不应先注意到滤镜。
- 让不同版本是同一原片的可信调色选择，而非互不相干的风格扮演。
- 让风格强度与素材承受能力匹配；监控、档案、新闻等画面默认保留媒介身份。
- 避免复制单一在世创作者的独特风格；改用时代、媒介、光线、构图、色彩和运动等可观察特征描述方向。
